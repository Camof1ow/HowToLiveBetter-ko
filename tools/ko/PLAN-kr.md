## `_kr` 생성 방식
- 각 절 파일 `NN-제목-kr.md` 생성(현 파일 옆). README `](book/...)` 목록을 _kr로 전환(SEAM 게이트 자동 검증), 구버전 번역파일은 삭제(커밋 이력 보존).
- 기계태그·등급문자·항목번호 불변량 유지(영어판처럼 태그를 번역하지 않음 — 우리 파서와 짝).
