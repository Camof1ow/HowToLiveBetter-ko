# 가성비 인생 가이드 — 한국어 발췌판

원작 「高性价比人生指南」(34절 667항)를 한국어로 옮긴 발췌판이다. 원작은 중국 대륙의 법령·의료보험·사회보험·행정 절차를 기준으로 쓰인 생활 판단 목록이고, 이 발췌판은 제도와 무관한 11절 241항을 먼저 담았다. 남은 23절(법률·노동·보험·절차)은 중국 규정이 아니라 **대한민국 현행 기준(법령·건보·통계)으로 재작성**할 예정이며, 원문에서 '争议'와 '待核实'은 기계 판독용 원 토큰으로 중국어 그대로 남아 있다.<br>
수록 241항. 매 항목에 무엇을 쓰고 무엇을 얻는지, 증거가 얼마나 단단한지 명시했다. 인용 원칙(우선순위): **① 대한민국 원천 — 통계청 원시 자료와 식약처·질병관리청 등 공식 통계를 근거로 삼고, 모든 수치는 원본(통계표·법령 원문)을 직접 대조해 더블체크. ② 국내 원천이 없으면 서구권 1차 연구(메타분석·RCT·대형 코호트)와 출처(DOI·PubMed·WHO/CDC)를 명확히 기입. ③ 중국 통계·시험은 해당 주제의 세계 유일한 1차 데이터일 때만 병기**(해당 항목은 한국 기준 재작성 대상 `[C]` 표시). 2차 전언은 인용하지 않는다.

전부 다 할 필요는 없다: 이건 가성비 순으로 정렬해 둔 선택지 목록이지 과제 목록이 아니다 — 한두 개만 건져도 성공이고, 저자 스스로도 대부분을 못 지켰다.

**이 프로젝트는 어떤 토큰이나 디지털 자산도 발행한 적이 없고, 앞으로도 발행하지 않는다.** 프로젝트 이름을 도용해 발행한 코인은 전부 이 프로젝트와 무관하며, 저자는 관련 수익을 수령도 주장도 하지 않는다. 그런 코인은 사기로 보고 사지 말 것 — 제5절 45항(가상화폐를 사지 말 것) 참조 (C단계 예정).

## 읽는 법

- **전부 다 할 필요는 없다**: 이건 가성비 순으로 정렬해 둔 선택지 목록이지 과제 목록이 아니다. 한두 개만 건져도 성공이고, 나머지는 둬야 필요할 때 다시 찾아본다. '말은 쉽지만 실행이 어렵다'는 평가는 옳다 — 저자 스스로도 대부분을 못 지켰고, 적어 둔 건 쓸 일 있을 때 찾기 위해서다. 적은 힘으로 할 것을 고르려면 아래 '가장 할 가치 있는 것만 보고 싶다' 항목을 볼 것.
- **AI로 찾게 하기**: 저장소에 중국어 skill([skills/life-decision-guide](skills/life-decision-guide/))이 들어 있고, Claude Code와 Codex 모두 설치할 수 있다. 설치 뒤 바로 "친구 대신 보증 서줄까" "매일 통근 2시간, 값어치 있나"라고 물으면, 관련 항목을 본문에서 먼저 찾아낸 뒤 책의 계산 방식으로 정렬해 답하고, 제몇절 제몇항인지도 밝힌다. 못 찾으면 못 찾는다 하고 숫자를 지어내지 않는다. 설치법은 [해당 디렉터리의 설명](skills/life-decision-guide/README.md) 참조.
- **조건으로 골라 보기**: [온라인 검색 페이지](https://camof1ow.github.io/HowToLiveBetter-ko/)를 열면 키워드·챕터·증거 등급으로 필터링할 수 있고, '돈을 쓰나, 시간을 쓰나, 인내가 필요하나는' 세 항목으로도 거를 수 있으며 여러 조건을 겹쳐 쓸 수 있다. 페이지 내용은 book/ 디렉터리의 본문에서 직접 가져오므로, 본문이 바뀌면 페이지도 따라 바뀐다.
- **항목끼리 서로 길잡이한다**('제8절 17항 참조' 같은 식): 검색 페이지에서는 이런 참조에 점선이 그인다. 클릭하면 그 항목의 제목과 '쉬운 말'이 제자리에서 펼쳐진다. 정말 건너뛰려면 '건너뛰기'를 누를 것. 그 항목이 마침 필터에 가려져 있으면 페이지가 필터를 자동으로 비운다. GitHub에서 직접 본문을 읽을 때는 클릭이 안 되지만, 모든 참조 뒤에 무엇을 가리키는지 적어 둔다('18항 참조(빌려줄 때 차용증 명확히 작성)'). 건너뛰지 않아도 무슨 항목인지 알 수 있다.
- **순서대로 읽고 싶다면**: 각 절 안의 항목은 가성비 높은 순으로 배열되어 있으니, 각 절의 앞쪽 몇 개부터 보면 된다.
- **오프라인 열람, 남에게 보내기**: [오프라인 단일 파일 HTML](https://github.com/eternity4719/HowToLiveBetter/releases/download/epub-latest/HowToLiveBetter.html)을 다운로드하면 책 전체가 검색·필터 기능과 함께 파일 하나로 들어 있다. 더블클릭하면 열리고, 서버도 인터넷도 필요 없고, 위챗으로도 바로 전송할 수 있다.
- **인쇄나 모바일 열람**: [PDF](https://github.com/eternity4719/HowToLiveBetter/releases/download/epub-latest/HowToLiveBetter.pdf) 다운로드. A4 조판, 이백쪽 남짓, 목차 쪽수와 북마크가 있고, 각 절이 새 페이지에서 시작한다.
- **Kindle 등 다른 리더기**: [EPUB](https://github.com/eternity4719/HowToLiveBetter/releases/download/epub-latest/HowToLiveBetter.epub) 다운로드. Kindle은 Send to Kindle로 보내면 된다.
- **세 가지 모두 본문이 업데이트될 때마다 자동 재생성된다.** 다운로드 링크는 고정이라 변하지 않는다. 한 번 받아 두거나 돌려본 사본은 따라 업데이트되지 않으니, 온라인판을 기준으로 할 것.
- **숫자의 의미**: 모든 항목에 '쉬운 말' 한 줄이 있다. '혜택' 칸의 연구 용어 표현을 "동일 기간 사망 확률이 약 2할 낮음", "구류 며칠, 벌금 얼마" 같은 일상말로 바꿔 놓았다. '혜택' 칸에 이미 있는 내용만 쓰고 새 숫자를 보태지 않는다. 이 한 줄만 봐도 판단이 선다. '혜택' 칸에는 모든 숫자가 원형대로 남아 있으니 직접 확인하려면 그 칸을 보면 된다.
- **결론이 가장 단단한 것만**: 검색 페이지에서 증거 등급 A를 체크하면, 구체적 숫자가 있고 메타분석이나 대형 시험에서 나온 114개만 남는다.
- **가장 할 가치 있는 것만**: 가성비 '극고'를 체크하면, 돈도 안 들고 시간도 안 들고 인내도 필요 없고 혜택은 최상위에 속하는 40개가 나온다. 거기에 '무엇을 얻나'를 하나 더 겹치면, 그 기준에서의 우선순위 목록이 된다.
- **'~하지 말기'로 시작하는 절 제목에 긴장할 필요는 없다**: 절 제목은 그 절에서 막아 두려는 일을 말하는 것(일찍 죽지 말기, 시간 낭비하지 말기)이지, 밑의 항목이 죄다 무언가 하지 말라는 뜻이 아니다. 실제로 할 동작은 항목 제목에 있고, 모두 동사로 시작하며 '할 일'인지 '말 일'인지 스스로 밝힌다. 같은 절에도 두 종류가 다 있다: 제4절에는 "「할 생각」을 「몇 시에, 어디서, 뭘 만나면 어떻게 할지」로 적어라"도 있고 "TV와 롤링 뉴스 보지 말기"도 있다. 항목 제목대로 읽고, 절 제목의 어조에 맞추지 말 것.

각 권고의 모양은 이렇다:

```markdown
### 9. 집의 소금을 저나트륨염(칼륨염)으로 바꾼다
- 비용: 한 봉지에 일반 소금보다 몇 위안 비싸다. 살 때 그냥 바꾸면 되니 따로 시간 안 든다. 맛은 거의 그대로다.
- 쉬운 말: 뇌졸중에 걸린 적 있거나 60세 이상으로 고혈압인 사람은 집 소금을 저나트륨염으로 바꾸면 5년 내 사망 확률이 약 12% 낮아지고, 뇌졸중은 약 14% 낮아진다.
- 혜택: 사람을 무작위로 두 그룹으로 나눈 시험으로, 중국 농촌에서 했다. 20995명은 모두 뇌졸중 병력자이거나 60세 이상 고혈압 환자였고, 4.74년 추적했다. 결과: 저나트륨염 그룹이 일반 소금 그룹보다 사망 위험이 약 12% 낮았다(RR 0.88). 뇌졸중은 약 14%(RR 0.86), 주요 심혈관 사건은 약 13%(RR 0.87) 낮았다.
- 증거 등급: A
- 출처: Neal B 외 (2021). Effect of Salt Substitution on Cardiovascular Events and Death. NEJM. <https://doi.org/10.1056/NEJMoa2105675>
- 비고: 争议. 대상은 위험군 고령자라 건강한 젊은 사람이 바꿔도 이득은 훨씬 작다. 신장 기능이 나쁘거나 칼륨 보유 약을 복용 중이면 바꾸기 전에 의사에게 물어보라.
```

## 직접 배포하기

대부분은 깔 필요가 없다: [온라인 검색 페이지](https://camof1ow.github.io/HowToLiveBetter-ko/)가 이미 있고, 오프라인 단 파일판·PDF·EPUB는 원작 저장소의 [Release](https://github.com/eternity4719/HowToLiveBetter/releases/tag/epub-latest)(중국어)에서 내려받을 수 있다. 한국어판 자동 빌드는 재작성 단계에서 다시 붙인다.

정말 내 PC나 서버에서 돌리려면:

```bash
git clone https://github.com/Camof1ow/HowToLiveBetter-ko.git
cd HowToLiveBetter-ko
python -m http.server 8000
```

그 다음 브라우저에서 `http://localhost:8000/`를 연다. 검색 페이지는 완전 정적이고, `README.md`와 `book/`이 그대로 데이터다. 백엔드도 DB도 의존성 설치도 없다. 통째로 아무 정적 서버(Nginx, GitHub Pages, object storage)에 올려도 결과는 같다. 단 `index.html`은 http로 열 것. 로컬 파일을 더블클릭하면 흰 화면이 뜬다 — 브라우저가 웹 페이지의 로컬 파일 읽기를 막기 때문이다. 그런 상황이라면 위의 오프라인 단일 파일을 쓸 것.

세 가지 전자판을 직접 만들고 싶다면 (평시에 필요 없다, Release에 있는 게 자동 생성본이다):

```bash
cd tools/epub && npm ci && npm run build   # EPUB
node tools/offline/build.mjs               # 离线单文件 HTML
node tools/pdf/build.mjs                   # PDF，另需 pandoc ≥ 3.1 和 typst ≥ 0.13
```

산출물은 모두 `dist/`에 있다.

## 네 가지 자원

이 책이 지키려는 건 수명만이 아니다. 통째로 네 가지다:

- **수명**: 더 오래 살고, 막을 수 있던 죽음에 덜 죽는 것
- **시간과 정력**: 살아 있는 시간을 보상 없는 일에 쓰지 않고, 매일의 주의력과 체력이 헛되 소모되는 것을 줄이는 것
- **돈**: 생떼 쓰듯 빠져나가는 헛돈을 줄이고, 수익이 확실히 보이는 곳에 쓰는 것
- **신체적 자유**: 한 줄의 금지를 몰라 유치장이나 구치소에 들어가는 일이 없도록 하는 것

모든 권고는 두 질문에 답한다: 무엇을 쓰나(돈/시간/정력/인내), 무엇을 얻나(총 사망률 변화 / 특정 사인 감소 / 시간·정력 절약 / 돈 절약 / 안전보장·신체적 자유). 항목은 분류가 아니라 가성비 순으로 배열한다: 원가는 거의 안 들고 되돌려지는 혜택은 큰 것을 맨 앞에 둔다.

**한 권고의 혜택이 누구에게 떨어지는지는 등급이 나뉘어 있다.** '이 혜택이 앞으로 자기에게 돌아올 확률'의 높낮이로: ① **자기 자신**; ② **배우자와 직계 친족**(부모, 자녀, 조부모·외조부모, 손자녀·외손자녀); ③ **친구·동료·기타 친족** — 상호주의 관계로, 베푼 것이 돌아올 수 있다; ④ **남** — 최하 등급이지만 0은 아니다: 확률이 작고 상대의 성정도 모르며, 협박·무고·보복의 면도 있다. 등급은 합산하지 않고, ④ 등급을 쓸 때는 혜택과 리스크를 함께 적는다.

응급 구조 편은 이렇게 읽을 것: 중국에서 발생한 원외(院外, 병원 도착 전) 심장정지 38,227건 중 79.2%가 집에서 발생했고, 가슴 압박을 배우는 건 먼저 피붙이에게 하기 위함이다. '익사하는 사람을 봐도 물에 안 들어간다' '패싸움을 봐도 몸으로 말리지 않는다' 같은 규칙 자체가 자구 규칙이고, 막는 건 방관자가 두 번째 부상자로 변하는 일이다. 남에게 손을 내밀지는 본인의 저울질이고, 항목에서는 면책 조항, 자구 동작, 리스크 면을 다 명시해 주되, '반드시 해야 할 이유'로 대신 계산해 주지는 않는다.

사망률 숫자, 시간·정력 숫자, 돈 숫자, 법적 후과는 각각 따로 계산하고 서로 환산하지 않는다. 이 네 가지는 검색 페이지의 '무엇을 얻나' 네 항목에 대응하며, 상호 간 크기를 비교하지 않는다.

## 증거 등급

모든 권고에 증거 등급을 붙였다:

| 등급 | 의미 |
| --- | --- |
| A | 구체적 숫자가 확인 가능하다. 출처는 복수 연구를 합친 메타분석, 다수를 장기간 추적한 대형 코호트, 무작위 대조 시험(RCT)이고, 얼마나 내려갔는지(HR, RR, 하락률) 말할 수 있다 |
| B | 연구 지지는 있으나 정확한 숫자를 못 대고, 소표본이나 단일 연구만 뒷받침한다 |
| C | 저자 본인의 경험이나 업계의 통설이고, 직접적인 연구 문헌이 없다 |

수록 241항 중 A급 114, B급 109, C급 18이다. 별도로 38항에 논쟁('争议')을 표시했고, 1곳에 미확인(待核实)이 있다. 논쟁 있는 A/B급 항목에는 '争议'를 표시하고 반대측 증거를 함께 싣는다. 모든 출처는 원문헌만 인용한다(학술지 논문은 DOI 또는 PubMed 링크, WHO/CDC 등 공식 기관 보고서). 2차 전언은 인용하지 않는다. 서구권 1차 문헌이 없는 주제(중국 국내 절차·통계)에만 중국 자료를 싣고, 그 경우 한국 기준 재작성 대상임을 `[C]`로 표시한다. 불확실한 숫자는 '미확인(待核实)'으로 표시한다.

A급은 '구체 숫자가 있고 출처를 확인할 수 있다'만 말하지, 그 숫자가 반드시 인과를 반영하는지는 말하지 않는다. A급 안에는 무작위 대조 시험도 있고, 그룹을 나누지 않고 기록만 하는 추적 연구도 있다. 후자는 그 일 자체가 효과가 있었는지, 아니면 그 일을 하는 사람이 원래 더 건강했는지를 구분하지 못한다. 어느 쪽인지 혜택 칸을 보면 안다: '무작위로 두 그룹 나눈'이면 전자, '기록만, 무작위 아님'이면 후자다. 법률·정책 항목의 A급은 법 조항이나 공식 문서 원문을 인용했다는 뜻이다.

혜택 칸과 쉬운 말의 백분율은 대부분 '안 한 사람 대비 몇 할 낮은'이고, 100명 중 몇 명이 아니다. 같은 12%라도 애초 위험이 높은 노인에게서 줄어드는 사망자 수가, 애초 위험이 매우 낮은 청년보다 훨씬 많다. 그래서 쉬운 말에 적힌 '어떤 사람'을 먼저 보고, 그 다음 백분율을 볼 것.

## 가성비 등급

증거 등급은 '이 숫자가 신뢰 가능한가'만 답하고 '이 일이 할 값어치인가'는 답하지 않는다. 그래서 매 항목에 두 가지를 더 붙인다: 혜택 규모(얼마나 큰 이득인가)와 기준(어떤 종류의 것을 얻는가). 검색 페이지는 이 둘에 세 가지 비용을 합쳐 가성비 등급을 낸다:

| 차원 | 값 | 정하는 법 |
| --- | --- | --- |
| 기준 | 수명 교환 / 돈 교환 / 시간·정력 교환 / 신체적 자유 교환 | 그 항목이 주로 뭘 얻는지로 본다. **서로 다른 기준은 비교하지 않는다.** '총 사망률 12% 하락'과 '연 500위안 절약'은 자가 달라서 우열을 낼 수 없다 |
| 혜택 규모 | 대 / 중 / 소 | 느낌으로 하지 않고 항목 자체의 '혜택' 칸을 미리 정한 경계에 맞춘다: 수명은 몇 % 내려갔나(≥20% 대, 10–20% 중, <10%이거나 최종 결과가 아닌 중간 지표만 재면 소); 돈은 금액(원작 기준이 위안화: 1만 위안급 대, 수백~수천 위안 중, 수십 위안 소 — C단계에서 원화 환산 재기준); 신체적 자유는 후과(형사 책임 회피 대, 구류나 행정처분 회피 중, 민사 분쟁 회피 소); 시간·정력은 절약분(매일 시간급 대, 주 단위 시간급 중, 한 번만 절약되는 소) |
| 가성비 | 극고 / 고 / 보통 | 혜택이 크고 세 가지 비용이 전부 0 = 극고; 혜택 크고 비용 낮음, 또는 혜택 중이고 비용 0 = 고; 나머지 = 보통 |

수록 241항 중 가성비 극고 40(17%), 고 109(45%), 보통 92(38%). 중간 등급이 두꺼운 것은 의도된 것이다: 아래 혜택 규모가 본래 대·중·소 3등급뿐인데, 더 잘게 쪼개면 지어낸 정확도다.

**이 등급은 저자 본인의 판단이지 증거가 아니다.** 책의 기준으로 등급 자체가 C급에 불과하다. 증거 등급과 별개이며 서로 영향하지 않는다. 증거는 A급인데 가성비 보통일 수 있고(대상포진 백신에는 97.2% 효능의 3상 RCT가 있지만, 두 바늘에 3~4천 위안, 대상포진은 거의 목숨을 위협하지 않는다), 증거는 C급인데 가성비 극고일 수 있다(출국 전 일정을 가족에게 보내 두기). '보통'이 안 할 이유가 되진 않는다 — 책의 모든 항목은 하라는 권고이고, 다만 그 등급은 그 지출 값어치를 당신이 저울질해야 할 뿐이다.

## 숫자를 읽는 법 (용어사전)

본문은 일상 표현을 최대한 쓰지만, 연구를 인용하면 통계 용어가 몇 개 불가피하다. 모르면 이 표를 찾을 것; 온라인 검색 페이지에서 점선 있는 단어에 마우스를 올리면(모바일은 탭) 설명이 팝업된다.

<details>
<summary>용어 41개 펼치기 (총 사망률, HR, RR, 95% CI, 메타분석, BMI, LPR, 계약금과 예약금……)</summary>

| 용어 | 뜻 |
| --- | --- |
| 총 사망률 | 일정 기간 동안 한 집단에서 사망한 사람이 얼마나 되는지, 사인은 불문. 이 책에서 '오래 사나'를 잰다. 연구 원문에선 전사망률(全因死亡率), 약어 ACM |
| HR | 위험비(hazard ratio). 같은 기간에 어떤 일을 한 그룹이 사건(사망·발병)이 나는 빠르기를, 안 한 그룹으로 나눈 값. HR 0.87이면 안 한 그룹보다 13% 낮고, HR 1.21이면 21% 높다 |
| RR | 상대 위험도. 두 그룹에서 일이 날 가능성의 비이고, 숫자 읽는 법은 HR과 같다 |
| OR | 교차비(odds ratio). 역시 두 그룹 비교인데 계산법이 RR과 약간 다르다: 비교하는 일이 드물면 RR과 거의 같고, 일이 흔하면 실제보다 차이를 크게 말한다 |
| IRR | 발생률비. 발생률은 일정 기간 새로 그 병에 걸린 사람의 비율이고, 두 그룹을 나누고 읽는 법은 RR과 같다 |
| RaR | 발생횟수비. 몇 명이 당했가가 아니라 일이 몇 번 일어났는가(예: 낙상 횟수)를 비교하고, 읽는 법은 RR과 같다 |
| 표준화 사망비 | 약어 SMR. 그 집단에 실제 사망한 수를, '같은 나이의 일반인이 마땅히 사망했을 수'로 나눈 값. 5.86이면 같은 나이 또래의 5.86배로 사망했다는 뜻 |
| 위험차 | 두 그룹의 발생 확률을 빼서 '1,000명 중 몇 명이 더'를 직접 낸다. 배수는 몇 배라만 말하고, 위험차는 실제로 몇 명이 더 늘었는지 말한다 |
| 95% CI | 95% 신뢰구간. 연구로 나온 숫자는 오차가 있기 마련이고, 참값이 아마 들어 있는 구간이다. 배수형 숫자는 구간이 1을 넘어가고, 가감형은 0을 넘어가면, 두 그룹 차이는 우연일 수 있다는 뜻이고 본문엔 '통계적 유의성 없음'이라 쓴다 |
| RCT | 무작위 대조 시험. 제비뽑기처럼 사람을 두 그룹 나눠 한쪽은 그 일을 하고 한쪽은 안 한 뒤, 나중 결과 차이를 비교한다. '그 일이 효과가 있었다'를 보려면 가장 설득력 있는 방법 |
| 메타분석 | 여러 연구 결과를 모아 다시 계산해 하나의 총 숫자를 낸다. meta 분석이라고도 한다 |
| 코호트 | 코호트 연구. 큰 무리를 골라 수년간 추적하며 누가 일을 당했는지 기록한다. 두 일이 함께 나타나는지는 보이나, 앞의 일이 뒤의 일을 일으켰음을 증명하긴 부족하다 |
| 관찰 연구 | 연구자가 옆에서 기록만 하고, 누가 하고 안 하고를 배정하지 않는다. 결과가 다른 요인에 끌리기 쉬워(이 표의 혼잡·역인과 두 항목 참조) 숫자는 할인해 볼 것 |
| 혼잡(교란) | 앞 원인과 뒤 결과에 동시에 작용하는 제3의 요인 때문에 인과처럼 보이는 것. 예: 채소를 잘 먹는 사람은 운동도 좋아해서, 어느 쪽이 작용했는지 구분 못 한다 |
| 역인과 | 인과 방향이 뒤집힘: 앞이 뒤를 일으킨 듯 보이나 실제로는 뒤가 앞을 일으킨다. 잠 많이 자서 일찍 죽는 게 아니라, 병이 무거운 사람이 많이 잔 것이다 |
| d、g | 효과 크기. 두 그룹 차이가 얼마나 큰지를 뜻하고, 차이를 '통적 변동폭의 몇 배'로 환산한다: 0.2 작음, 0.5 중간, 0.8 큼 |
| r | 상관계수. 두 일이 함께 얼마나 강하게 움직이는지, 값은 -1에서 1. 0.1 약함, 0.3 중간, 0.5 강함 |
| MET | 운동 강도 단위. 조용히 앉아 있으면 1 MET, 빠른 걷기 약 3~4 MET. MET·h로 쓰면 강도×시간으로, 통째로 얼마나 움직였는지를 뜻한다 |
| GRADE | 국제적으로 통용되는 채점법으로, 하나의 증거가 얼마나 신뢰할 수 있는지 높음·중간·낮음·매우 낮음 4등급으로 매긴다 |
| 의도 스크리닝 분석 | 효과를 계산할 때 '스크리닝받으라 통보받은 사람' 기준으로 하고 '실제로 받은 사람' 기준으로는 하지 않는다. 통보받은 쪽엔 안 간 사람이 꼭 섞여 있어, 이 계산법은 실제로 받은 사람에게 스크리닝이 주는 혜택을 낮춰 잡는다 |
| 팩년(pack-year) | 흡연 총량을 세는 단위. 하루 몇 갑 × 몇 해로, 30팩년이면 하루 한 갑씩 30년 핀 것 |
| BMI | 체질량지수, 비만도를 볼 때 흔히 쓰는 숫자: 몸무게 kg를 키(m)의 제곱으로 나눈다 |
| LDL | 저밀도 지단백 콜레스테롤, 속칭 '나쁜' 콜레스테롤 |
| eGFR | 추정 신장사구체여과율. 신장의 여과 능력을 재는 지표로 단위는 mL/min/1.73 m². 낮을수록 신장 기능이 나쁘고, 만성신장병의 단계를 이걸로 정한다 |
| HBsAg | B형간염 표면항원. 검사 항목으로, 양성이면 B형간염 바이러스에 이미 감염된 것 |
| HPV | 인유두종바이러스. 여러 유형이 있고 그중 일부 유형의 장기 감염은 자궁경부암으로 이어진다 |
| LDCT | 저선량 흉부 CT. 피폭량은 일반 CT의 5분의 1에서 10분의 1 정도 |
| PM2.5 | 공기 중에 떠다니는 미세 입자로, 지름 2.5마이크로미터 이하 |
| NOVA | 식품을 가공 정도에 따라 4분류한 방법. '초가공 식품'은 그중 4류 |
| LPR | 대출 시장 기준 금리(贷款市场报价利率). 중국 대출 금리의 기준이고, 매달 20일 발표된다. 주택담보 이자율과 민간대여 이자 상한이 이걸 따라 계산된다 |
| 노동중재 단심 종결(一裁终局) | 중국 노동중재 판정이 나면 그대로 발효되고, 회사가 같은 일로 법원에 다시 소송할 수 없다 |
| 조혼인율·조이혼율 | 중국에서 1,000명 중 그해 혼인·이혼 등록 건수. 이 밖에 '이혼/혼인 비'라는 숫자도 있는데, 그해 이혼 건수를 혼인 건수로 나눈 것으로 위 둘과 다른 것이니 섞어 보지 말 것 |
| AED | 자동 제세동기. 공공장소에서 흔히 보이는 빨간이나 노란 구급 상자. 켜면 음성 안내대로 하면 되고, 전기충격 필요 여부는 저 혼자 판단한다 |
| CPR | 심폐소생술. 심장정지 시 가슴을 강하게 압박해 피가 도는 것을 유지한다 |
| 3C 인증 | 중국 CCC(강제제품인증) 마크. 목록에 오른 제품은 이 마크 없이는 출고도 판매도 안 된다 |

2. [천천히 죽지 말기](book/02-不要慢慢死.md): 담배·술·운동·수면·식사(저나트륨염, 견과류, 전곡류, 가공육, 포장 없이 떠다 파는 자가 착유 땅콩기름, 식물성 유지로 라드를 대체), 수좌, 그리고 금연 금주의 구체적 방법(금연약, 금연일, 금연클리닉과 핫라인, 전자담배, 음주 금단증은 혼자 버티면 안 됨), 낮잠 길이, 밤샘 후 회복법, 야간근무 연수의 계산, 조리 시 환풍기 켜기. 기준: 총 사망률 또는 특정 사인. 긴 글: [생체시계와 야간근무](docs/生物钟和夜班.md).
3. [정력 낭비하지 말기](book/03-不要浪费精力.md): 수면, 방해, 멀티태스킹, 인간관계 부채, 기관을 상대할 때 마땅히 가져야 할 기대. 기준: 정력/시간.

30. [학교에 간 아이](book/30-上学以后的孩子.md): 시간 단위로 재는 급성 질환, 시험 때문에 치료 미루지 말기, 괴롭힘 대응, 매일 야외 2시간, 학생 건강검진 통보서, 청소년 우울증 스크리닝, 근시 '치유' 제품, 수면과 숙제의 절대 규칙, 휴학과 학적 보존, 산동안 검안과 재검, 치아 홈 메우기, 때리지 않고 소리치지 않고 훈육하기, 학부모 수업, 인터넷 중독 치료학교 보내지 말기. 기준: 사망률과 건강 종점, 돈과 시간은 각 한두 개.
31. 열여덟 이후의 길 (C단계 예정): 중국에서 열두 개의 길의 법정 문턱. 군 입대(중국 병역 등록, 의무역 2년, 병역 거부 시 연대 제재, 등록금 보충과 진학, 배치와 전역 후 30일 내 신고, 전역금과 근속연수·세금); 기층 서비스 항목의 정향 채용; 특강 교사 임기 종료 후 정규직 전환; 소방대와 군무원; 독학시험, 성인고시, 개방대학; 공비 사범생과 정향 의료생의 6년 이행; 해외 노동은 어떤 회사를 찾아야 하나; 집에서 국외 회사 원격 일하기의 개인소득세와 외화 수령; 창업 보증 대출; 프리랜서·일용직의 사회보험; 배달원의 직업 재해 보장. 기준: 돈/시간, 병역 거부 항목은 신체적 자유를 포괄.
32. 유학: 신분·알바·보험과 귀국 인증 (C단계 예정): 등록금 내기 전 인증 학교 목록 확인; 미국 F-1 '최장 4년, 수료 30일 내 출국' 신설이 법원에서 정지되어, 당분간은 수료까지와 60일 유예; 미국·캐나다·영국·호주 4개국 근로 시간 상한; 전일제 재학이 신분의 토대; 이사 10일 내 신고; 중국 교육부 유학 경보; 호주 OSHC는 끊으면 안 됨; 영국 의료 부가금; 중국 유학서비스센터 인증 10~20 영업일; 유학생 심사 강화 대상 학교 목록. 기준: 돈/신체적 자유.
33. 장애 이후 사는 법 (C단계 예정): 자율신경 반사이상의 현장 세 단계, 장애 후 10년의 자살 창구, 중국 정신장해 입원의 자발 원칙과 두 가지 예외, 보호자 자신의 사망 리스크, 휠체어 감압 방석, '치유' 사기, 증명한 뒤 빠짐없이 물어야 할 여섯 가지 대우, 장기요양보험은 노인만 대상 아님, 0~6세 재활 구제, 가정 배리어프리 개조 보조금, 비례 고용과 장애고용금, 개인소득세 감면, 안내견과 무료 승차, 중국 대학입시(高考)의 합리적 배려, 학교는 수용 거부 못 함과 가정 방문 수업, 중국 C5 운전면허, 재활기관 고르는 법, 보청기, 행위능력 인정과 후견. 기준: 사망률/돈/시간/신체적 자유.
34. [집 상비약, 사고 내지 말기](book/34-家里的常备药别吃出事.md): 아세트아미노폴 중복 복용 말기, 아이 해열엔 아스피린·니메술리드·메타미졸 안 쓰기, 이부프로펜 위에 해치는 고위험군, 2세 미만은 종합 감기약 임의 투약 말기, 임신 20주 이후 이부프로펜 임의 복용 말기, 오메프라졸 자가 복용 최장 7일, 감기에 항생제 불필요, 설사는 보충액부터, 아이에 지사제 안 주기, 진통제 과용이 오히려 두통, 유통기한 지난 약·남은 약은 유해 폐기물로, 세팔로스포린·메트로니다졸 복용 중과 중단 후 7일은 술 금지. 기준: 사망률.

각 절의 항목은 가성비 높은 순으로 배열했다. '일찍 죽지 말기' '시간 낭비하지 말기' 같은 절 제목은 그 절에서 막아 두려는 결과를 말하고, 항목의 실행 여부는 항목 제목이 기준이다. 긴 글 별도: [가정 비상 구급 키트 목록](docs/家庭应急装备清单.md), 플랫폼 운영에 필요한 허가증 (C단계 예정), 결혼은 이득인가 (C단계 예정), 낯선 사람이 사고를 당했을 때 멈춰야 하는가 (C단계 예정), [생체시계와 야간근무](docs/生物钟和夜班.md), 그리고 시간 순으로 배열한 네 개의 상황 체크리스트: 해고당한 뒤 먼저 할 일 (C단계 예정), 아이 출생 전후 처리 서류 (C단계 예정), 만성질환 확진 직후 (C단계 예정), 이직·이사 전에 (C단계 예정). 모든 출처의 검증 과정은 [docs/核实记录](docs/核实记录/)에 있다.

원작은 Claude Code의 도움으로 작성됐고(원문헌 찾기·숫자 대조·참조 유지, 주제 선정과 최종 심사는 원저자 책임), 이 한국어 발췌판은 omp 에이전트로 번역·자동 검수했다(항목 수·비용 태그·증거 등급·URL 집합 원문 대조). 모든 숫자는 출처 칸의 원문에서 확인할 수 있다.

저장소 루트의 `index.html`이 온라인 검색 페이지다: 키워드·챕터·증거 등급과 비용 차원(돈, 시간, 인내)으로 항목을 필터링하고, 데이터를 이 저장소에서 직접 읽는다. 저장소 설정에서 GitHub Pages를 켜면(Deploy from a branch, branch main, /) 바로 접속할 수 있다. `tools/epub/`은 전자책 생성 스크립트이고, `cd tools/epub && npm ci && npm run build`로 로컬에서 EPUB 한 권을 `dist/`에 낸다. GitHub Actions가 본문 변경 후 같은 스크립트를 자동으로 돌려 Release를 갱신한다.
